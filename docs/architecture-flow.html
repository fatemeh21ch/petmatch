معماری پت‌مچ

از فید خام هفت پت‌شاپ تا «بهترین خرید» برای حیوان شما: چه زبانی، چه کتابخانه‌ای، چه نوع جست‌وجویی و چه داده‌ای، و هر درخواست دقیقاً از کجا می‌گذرد.

پاسخ کوتاهلایه‌هامسیر داده مسیر یک جست‌وجوزبان و کتابخانهدیتاست‌ها
جست‌وجوموتور جست‌وجوی جدا (Elasticsearch یا Meilisearch) نداریم. جست‌وجو درون‌حافظه و با پایتون است: قواعد و regex فارسی برای فهم نیت، واژه‌نامه برند و ویژگی (kb.py)، و تطبیق فازی RapidFuzz برای غلط تایپی. بعد فیلتر و رتبه‌بندی با فرمول ارزش خرید. برای نسخه واقعی Meilisearch در نظر گرفته شده.
زبان‌هابک‌اند Python 3.11 با FastAPI؛ فرانت TypeScript با Next.js 16 و React 19؛ استایل CSS ساده؛ همه تصویرها SVG دست‌ساز.
دادهدیتابیس نداریم؛ همه‌چیز فایل JSON و CSV است. ۷ فید ساختگی ولی واقعی‌نما (۲۶۸ آگهی) که seed/generate.py می‌سازد، برچسب مرجع تطبیق، ۹۰ روز تاریخچه قیمت و ۳۰ روز آمار نمایشی.
هوش مصنوعیاختیاری، فقط با ANTHROPIC_API_KEY: مدل claude-opus-5-5 در دو جا، یکی فهم جمله‌ای که قواعد نفهمیدند و یکی نوشتن خلاصه از دلیل‌های محاسبه‌شده. بدون کلید هم کل محصول کار می‌کند.
